Trust your home apps

Install this certificate once on this device, and every https://*.__DOMAIN__ app shows a padlock.

Download the certificate

SHA-256 fingerprint, to compare with ops-app ca on the server:
__FP__

  • iPhone/iPad: open this page in Safari, download, then Settings → Profile Downloaded → Install. Then Settings → General → About → Certificate Trust Settings → turn it on.
  • Android: Settings → Security → Encryption & credentials → Install a certificate → CA certificate.
  • macOS: open the file → Keychain Access → double-click it → Trust → Always Trust.
  • Windows: double-click → Install Certificate → Local Machine → Trusted Root Certification Authorities.
  • Linux: sudo trust anchor --store home-apps-root.crt (Arch), or copy to /usr/local/share/ca-certificates/ and run sudo update-ca-certificates (Debian/Ubuntu).
  • Firefox uses its own list: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
